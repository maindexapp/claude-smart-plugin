# Maindex for Claude

Persistent, relational memory for AI agents and their humans.

[Website](https://maindex.io) | [Help & FAQ](https://maindex.io/help) | [Dashboard](https://maindex.io/dashboard)

This plugin connects Claude to **Maindex Smart** — a streamlined knowledge graph with four intuitive tools:

- **keep** — store a new memory
- **recall** — search and retrieve memories
- **update** — revise an existing memory
- **forget** — remove a memory

## Installation

Install from the Claude Plugin Marketplace, or add the `.mcp.json` configuration to your Claude project.

## Authentication

On first use, you'll be redirected to [maindex.io](https://maindex.io) to sign in and authorize the connection.

## Looking for More Tools?

If you need direct access to the full Maindex API — typed associations, collections, bulk operations, graph traversal, and MCP resources — use the **Expert** plugin:

- [claude-expert-plugin](https://github.com/maindexapp/claude-expert-plugin) — 14 tools + 5 resources
